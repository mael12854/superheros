08 — POUR CLAUDE CODE · TECHNIQUE

Comment le site est construit

Hébergement sur Vercel. Données dans Vercel Blob. Pas de Supabase, pas de GitHub Issues. Toutes les vérifications se font dans des routes API, jamais dans le navigateur.

1 · NavigateurL'agent tape ses réponses. Le navigateur les envoie, c'est tout.
2 · Route APILe « vigile » sur le serveur Vercel. Lit la fiche, compare, décide.
3 · Vercel BlobLe « carnet du vigile ». Fiches des agents et registre, en privé.
4 · RéponseLe navigateur reçoit seulement { "acces": "OUI" } ou "NON".
Fichiers dans Vercel Blob agents/<id>.json
registre/AAAA-MM-JJ.json
missions/<id>.json
gadgets.json
photos/<id>.jpg
Routes API POST /api/entree → OUI / NON
POST /api/sortie/etape → OUI / NON
POST /api/agents (chef)
GET /api/registre?date=
GET /api/presents
POST /api/code/nouveau
Règles de sécurité · Le jeton Blob reste sur le serveur (variable d'environnement). · Les fichiers Blob en accès privé, jamais d'URL publique renvoyée. · Codes secrets hachés (bcrypt), jamais en clair. · Comparaison sans majuscules ni accents. · Compteur d'échecs côté serveur (3 NON = blocage 1 min). · Les réponses de l'entrée ne disent jamais quel champ est faux.

09 — LES OUTILS DU QG

18 outils à construire

Commencer par les outils PRIORITÉ. Chaque outil suit cette charte : mêmes couleurs, polices, boutons et une question par écran.

Contrôle d'entréePRIORITÉ
16 questions, une par écran. Envoie tout à /api/entree, reçoit OUI ou NON. Note l'heure dans le registre.
Contrôle de sortiePRIORITÉ
8 questions, vérifiées une par une via /api/sortie. Faute d'1 lettre acceptée.
Fiche d'inscriptionPRIORITÉ
Crée un nouvel agent : tous les champs de la fiche + photo. Réservée à Maël et Marin (code chef).
Générateur de code secretPRIORITÉ
Tire 4 chiffres au hasard, refuse les codes trop faciles (1234, 0000, 1111) et ceux déjà pris.
Registre des visiteursPRIORITÉ
Liste du jour : qui est entré, qui est sorti, à quelle heure. Filtre par date.
Badge imprimablePRIORITÉ
Carte format carte bancaire (85 × 54 mm) : photo, nom de héros, n° d'agent, logo. Jamais le code secret.
Tableau « Qui est au QG ? »BONUS
Écran géant avec les agents présents en ce moment. Vert = dedans, gris = dehors.
AlarmeBONUS
Écran rouge clignotant + son après 3 NON à l'entrée. Seul un chef peut l'arrêter.
Mot de passe du jourBONUS
Un mot change chaque matin. Les chefs le disent à voix haute aux agents.
Messages secretsBONUS
Code et décode un message avec le code César (décalage de lettres).
Journal de missionBONUS
Chaque mission : nom, date, agents, résultat (réussie / ratée / en cours).
AnniversairesBONUS
Les prochains anniversaires des agents, calculés avec leur date de naissance.
Menu du QGBONUS
Propose un menu entrée-plat-dessert avec les plats préférés des agents présents.
Test de recrutementBONUS
Quiz pour devenir agent. Si réussi : ouvre la fiche d'inscription.
Diplôme d'agentBONUS
Certificat A4 imprimable avec nom de héros, date et signatures des chefs.
Inventaire des gadgetsBONUS
Liste des objets du QG : qui l'a emprunté, quand il doit le rendre.
Liste rougeBONUS
Personnes interdites au QG (petite sœur, chat…). Accès refusé direct.
Chronomètre de missionBONUS
Compte à rebours plein écran, alarme à la fin.
